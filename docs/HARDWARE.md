# Hardware validation matrix

Reference desktop: HP Omen 30L-class system used during V0.x field tests.

For every candidate record:

- BIOS/UEFI version
- CPU
- GPU + active kernel/userspace driver
- RAM
- display model, resolution, refresh, scaling
- keyboard/mouse connection type
- audio devices
- network devices
- suspend/resume result
- USB-safe internal-disk result

“Detected” and “certified” are different states. Certification requires a real boot and user interaction test.
