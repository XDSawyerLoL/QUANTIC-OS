# Quantic OS brand reference

The visual source of truth is the approved Quantic Sillage brand board.

- Master palette: Midnight Navy `#0A1F3D`, Electric Cyan `#00D9FF`, Teal `#14B8A6`, Soft Silver `#C9D1D9`, White `#FFFFFF`.
- Quantic OS uses the thin circular Q + sillage emblem.
- Lockup: `Quantic OS` / `THE INTELLIGENCE LAYER` / `A MORE CAPABLE WORLD`.
- Do not replace this mark with the previous thick crescent/leaf variant.
